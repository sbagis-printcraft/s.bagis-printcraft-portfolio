# Site images

Put your real files here with these names (paths are set in `src/content/assets.ts`):

| File | Where it shows |
| --- | --- |
| `logo.png` | Header and footer logo |
| `portrait.jpg` | Hero photo (portrait 4:5, min 800×1000) |
| `flyer.jpg` | About section |
| `og-image.jpg` | Optional link-preview image (1200×630) |
| `projects/p1.jpg` … `projects/p12.jpg` | Project gallery and image viewer (ids match `src/content/site.ts`) |

Missing files show a tidy "coming soon" frame — no broken images.
